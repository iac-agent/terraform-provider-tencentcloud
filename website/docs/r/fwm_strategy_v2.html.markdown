# tencentcloud_fwm_strategy_v2

Provides a resource to create a FWM (Firewall Manager) strategy.

A FWM strategy describes the rule groups that are executed before and after the firewall, and the accounts or account groups the rules are delivered to. A single create request may generate more than one strategy, which is reflected in the computed `strategy` attribute.

## Example Usage

```hcl
resource "tencentcloud_fwm_account_group" "example" {
  group_name  = "tf-example"
  description = "remark."
}

resource "tencentcloud_fwm_strategy_v2" "example" {
  product         = "cfw"
  receive_account = ["100000000001"]
  receive_group   = [tencentcloud_fwm_account_group.example.group_id]

  pre_strategy {
    group_id = "grp-xxxxxxxx"
    sequence = 1
  }

  post_strategy {
    group_id = "grp-yyyyyyyy"
    sequence = 2
  }
}
```

## Argument Reference

The following arguments are supported:

* `product` - (Required, String) Type of the product the strategy belongs to.
* `post_strategy` - (Optional, List) Rule groups executed after the firewall.
* `pre_strategy` - (Optional, List) Rule groups executed before the firewall.
* `receive_account` - (Optional, Set) Uins of the accounts that receive the delivered rules.
* `receive_group` - (Optional, Set) IDs of the account groups that receive the delivered rules.

The `post_strategy` object supports the following:

* `group_id` - (Optional, String) Rule group ID.
* `sequence` - (Optional, Int) Priority of the rule group.

The `pre_strategy` object supports the following:

* `group_id` - (Optional, String) Rule group ID.
* `sequence` - (Optional, Int) Priority of the rule group.

## Attributes Reference

In addition to all arguments above, the following attributes are exported:

      * `app_id` - AppId of the member.
      * `member_id` - Member ID. Empty for personal accounts.
      * `nickname` - Nickname of the member.
      * `node_name` - Department the member belongs to.
      * `uin` - Uin of the member.
    * `members` - Members of the account group. Only returned when receiver_type is `1`.
    * `nickname` - Name of the tenant.
    * `receiver_type` - Receiver type. `0`: account uin, `1`: account group.
    * `uin` - Uin of the tenant.
  * `create_by` - Creator of the strategy.
  * `create_name` - Name of the creator.
  * `create_time` - Create time of the strategy.
  * `err_msg` - Reason why the delivery failed.
  * `error_type` - Type of the delivery failure reason.
  * `exec_area` - Execution area of the strategy.
  * `group_id` - Rule group ID.
  * `group_name` - Rule group name.
  * `receive_account` - Accounts that receive the delivered rules.
  * `rule_count` - Number of rules in the rule group.
  * `rule_status` - Status of the strategy.
  * `sequence` - Priority of the strategy.
  * `strategy_id` - Strategy ID.
  * `update_by` - Updater of the strategy.
  * `update_name` - Name of the updater.
  * `update_time` - Update time of the strategy.
* `id` - ID of the FWM strategy.
* `strategy` - Details of the strategies generated by the creation request.

## Import

FWM strategy can be imported using the strategy id, e.g.

```
terraform import tencentcloud_fwm_strategy_v2.example sg-xxxxxxxx
```

-> **Note:** When a single create request generated more than one strategy, the resource id is a list of strategy ids joined by `#`. Such a resource can be imported with the full joined id, and it can only be destroyed or recreated afterwards, because `ModifyStrategy` operates on a single strategy.
